# 카뮤니티 요구사항 분석 및 구현 현황

> 기준 SDK: Pleos Connect SDK — Vehicle 2.3.2 · NaviHelper 3.0.5 · TextToSpeech 3.3.1 · SpeechToText 3.3.1 · FusedLocation 1.1.3
>
> 상태 표기
> - **구현**: 실제로 동작하는 코드와 테스트가 있음
> - **모의**: SDK에 기능이 없어 인터페이스를 정의하고 같은 규칙으로 시뮬레이션함 (기획서에도 그렇게 적을 부분)
> - **2단계**: 기획안이 OEM 제휴·관리사무소 협약 이후로 둔 범위. 이번 구현에서는 제외

## 1. SDK 매핑 — 기획안 대비 실제 확인 결과

공식 문서와 SDK 바이너리(AAR)를 직접 열어 확인했습니다. 기획안의 가정 중 **두 군데를 고쳤습니다.**

| 기획안 | 실제 SDK | 구현에서 쓴 API | 비고 |
|---|---|---|---|
| Vehicle – DrivingMode로 주차·주행 전환 감지 | DrivingMode는 NORMAL/ECO/SPORT 주행 모드만 줌 | **Vehicle – Gear** `getCurrentGearSelectionState` / `registerGearSelection` (P·R·N·D) | ⚠️ **기획서 수정 필요**: "DrivingMode" → "Gear". Gear 도메인은 웹 문서 목록엔 없지만 SDK 2.3.2에 들어 있음 (권한 `CAR_DRIVE`). SDK가 "Google GEAR_SELECTION 속성(Android Automotive CarPropertyManager)을 쓰라"는 deprecated 표시를 달아 두어, 정식 출시 전에는 그쪽으로 옮기는 것이 안전함 |
| Vehicle – Door: 트렁크 1회 개방 | `DoorValue.REAR`(테일게이트) 영역의 `setDoorPosition` 지원 | `Door.setDoorPosition(DoorArea(REAR), max)` + `registerDoorPosition`으로 닫힘 감지 | 개방 최대값은 차종마다 달라 `checkDoorPositionCapabilities`로 읽음 |
| Vehicle – EvBattery: 충전 케이블, 잔량 | 충전 상태(`getEvChargeSwitchState`)와 잔량(SOC) 있음. 케이블 '연결' 자체 값은 없음 | 충전 중 → 인터록, SOC < 10% → 요청 거절 | 기획서 표현을 "충전 중"으로 맞추면 정확함 |
| Vehicle – Light: 비상등 상태 확인 | 비상등(hazard) API 없음. 미등·실내등 제어 가능 | **미등 점멸**(`setTailLampLightSwitch`)로 촬영·이동 고지 | ⚠️ **기획서 수정 권장**: "비상등" → "미등 점멸(비상등 API 부재)" |
| Vehicle – Odometer: 이동 거리, 복귀 거리 | km 단위 누적 주행거리 | 주행거리를 기록하고, 기어 신호가 없을 때 출차 보조 신호로 사용 | 3m 단위 정밀도는 실차 RSPA 연동(2단계)에서 휠 오도메트리로 |
| (기획안에 없음) 실내 사람·반려동물 감지 | **Seat – 착석 센서** `registerSeatOccupancy` | 실내 탑승자 인터록 | 기획안 표에 Seat SDK 추가 권장 |
| FusedLocation: 단지 지오펜스, 지하 추측항법 | `addProximityAlert`(ENTER/EXIT), 위치 업데이트 | 단지 반경 진입 = 입차 게이트, 이탈 = 토큰 무효 | `FUSED_LOCATION`은 dangerous 권한 → 실행 중 요청 |
| NaviHelper: 주차장 내 구역 표시 | 목적지·경유지·경로 요청 | 연동 코드만 포함 (`requestRoute`, `onDestinationArrived`). 지하주차장은 GPS 경로가 맞지 않아 '갈게요' 뒤 차량 화면 미니맵으로 칸 위치를 안내 | 지상·대형 주차장으로 확장할 때 경로 안내에 사용 |
| STT / TTS | 한국어 지원, ON_DEVICE 모드는 앱 등록 불필요 | 주차 직후 "오늘 밤 비켜줘를 켜 둘까요?" → '응', 빈자리 안내 → '갈게요' | Playground 자격 증명이 있으면 HYBRID |

추가로 확인한 제약
- `Safety.getTelltalesInfo`(주차브레이크 경고등 등)는 `PRIVATE_CAR_SAFETY`(signature) 권한이라 3rd party 앱이 쓸 수 없음 → 쓰지 않음
- 차속(speed) API 없음 → 주행 여부는 기어로 판정
- 차량 기울기 API 없음 → 경사 판정은 **단지 지도의 경사 구역**으로만 (기획안의 "차량 기울기 감지 또는" 부분은 2단계)

## 2. 기능 1 · 비켜줘

### 2-1. 1단계 중립 표시 (공모전 기간 구현)

| 요구사항 | 구현 | 상태 |
|---|---|---|
| 차주가 N 주차를 해 두고 '응'이라 답하면 '밀어도 되는 차'로 등록 | 주차 직후 음성 질문 → `voice-consent`. **기어가 실제로 N인지 Gear API로 검증**, 경사 구역이면 거절 | 구현 |
| 막힌 이웃이 번호판을 찍으면 "중립이에요, 평지에서 천천히 밀어주세요" | `POST /api/neutral-check` | 구현 |
| 아니면 "중립이 아니에요, 차주에게 알림을 보냈어요" + 차주 폰과 차량 화면에 동시 알림 | 사용자 채널 알림 + 차량 SSE `neutral.notice`(TTS로 읽음) | 구현 |
| 기어를 N에서 바꾸면 표시 해제 | 차량 앱이 보낸 기어 변화로 자동 해제 | 구현 |
| 방문자는 QR로 '차주에게 연락'만 | 로그인 없이 확인 시 연락만 | 구현 |
| 번호판 촬영 | 카메라로 찍고 사진을 보며 번호 입력 | 부분 (자동 인식 OCR은 미구현) |

### 2-2. 2단계 원격 비켜줘 (OEM 제휴 후 → 모의로 전체 흐름 시연)

| 요구사항 | 구현 | 상태 |
|---|---|---|
| 요청 → 차주 폰 30초 거부 창 → 차량 자가 점검 → 버튼 누르는 동안만 보행 속도로 최대 3m → P·EPB 체결, 전후 10초 영상·로그, 크레딧 | `moveRequests.js` 상태 머신 (VETO → PRECHECK → READY → MOVING/PAUSED → MOVED → RETURNING → RETURNED) | 구현 (이동은 모의) |
| 차주 '지금 허락' (거부 창 조기 종료) | `decision: approve` | 구현 |
| 복귀: 출차 후 '복귀'를 같은 방식으로 누르면 기억한 거리만큼 원위치 | `startReturn` + hold, 마지막으로 비켜준 차부터 | 구현 |
| 2단계 이동 규칙은 RSPA 안전 규칙 그대로 | `SimulatedRspaAdapter`(차량 앱), `virtualAgent.js`(서버 가상 차량)가 같은 규칙 | 모의 |

### 2-3. 세부 규칙

| 항목 | 기획안 규칙 | 구현 | 테스트 |
|---|---|---|---|
| 요청 자격 | 입주민 인증 + 실명 휴대폰 인증 계정. 방문자는 연락만 | `assertActive` | ✅ |
| 요청 대상 | '이중주차' 표시 또는 통로 지오펜스 안에 선 차만, 정식 칸은 불가 | `doubleParked` (통로 구역이면 자동) | ✅ |
| 이동 | 직진·후진만, 조향 없음, 보행 속도, 1회 최대 3m | 방향 앞/뒤, 0.5 m/s, 최대 3m(앞뒤 여유가 더 작으면 그만큼) | ✅ |
| 요청자 위치 | 차 측면 2m 안, 앞뒤 진로에 서 있으면 시작 안 됨 (기획안: BLE 근접 확인) | 요청자 체크 대신 차량이 BLE로 잰 거리·방향으로 판단(`proximity` 서비스). 보고가 3초 넘게 끊기면 정지. 트렁크·밀착 구역도 같은 방식 | ✅ (에뮬레이터에 BLE가 없어 측정값은 데모 콘솔이 입력) |
| 횟수 | 같은 차에 하루 1회, 요청자당 하루 3회, 같은 두 차 사이 크레딧 하루 1회 | `PAIR_DAILY`, `REQUESTER_DAILY`, `pairCreditedToday` | ✅ |
| 위임 토큰 하루 횟수 | 하루 2회(기본) | `VEHICLE_DAILY` (차주가 0~2회 설정) | ✅ |
| 시간 | 23~06시 기본 비활성, 켜 두면 야간 크레딧 가중 | `QUIET_HOURS`, ×1.5 | ✅ |
| 차주 거부 | 30초, 거부 시 "차주가 직접 처리합니다", 크레딧 차감 없음, 잦으면 위임 끄기 제안 | 최근 5건 중 3회 거부 시 제안 알림 | ✅ |
| 복귀 기한 | 출차 후 10분, 안 하면 차주 알림 + 요청자 크레딧 추가 차감, 차가 혼자 복귀하지 않음 | `RETURN_OVERDUE`, −50, 늦게라도 수동 복귀 가능 | ✅ |

> 기획안 안의 수치 충돌 정리: 세부 규칙의 "같은 차에 하루 1회"는 **같은 요청자 → 같은 차**로, 위임 토큰 표의 "하루 2회"는 **차 한 대가 하루 비켜주는 총 횟수**로 해석해 둘 다 적용했습니다. 기획서 문장도 이렇게 구분해 쓰면 혼동이 없습니다.

### 2-4. 예외 상황

| 상황 | 기획안 동작 | 구현 | 테스트 |
|---|---|---|---|
| 이동 방향에 사람·동물·차 | 즉시 정지, 5초 뒤 자동 재시도 3회, 계속 막히면 중단 + "진로를 비워 주세요" | RSPA 모의 + `ABORTED` | ✅ |
| 앞뒤 모두 막혀 공간 1m 미만 | "지금은 비킬 공간이 없어요" + 막고 있는 다음 차에 연쇄 요청 제안 | `NO_SPACE` + `suggestChain` | ✅ |
| 이중주차 여러 대 | 바깥쪽 차부터 토큰 차례로, 한 대라도 거부·불가면 전체 중단, 각각 3m | `targets[]` 순서, 전 차량 인터록 통과 후 시작 | ✅ |
| 경사로 | 비켜줘 비활성, N 주차도 금지 구역 안내 | 단지 지도 경사 구역 | ✅ |
| 충전 중 | "충전 중이라 움직일 수 없어요" | 요청 단계 + 인터록 이중 확인 | ✅ |
| 차 안에 사람·반려동물 | 요청 거부, 차주 알림 | Seat 착석 센서 | ✅ |
| 버튼에서 손을 떼거나 근접 범위 이탈 | 즉시 정지, 1분 안 재개, 지나면 토큰 소멸 | hold 신호 0.9초 끊기면 정지, 60초 뒤 `EXPIRED` | ✅ |
| 이동 중 접촉 | 즉시 정지, 양측 영상·로그, 복귀 금지, 운영사 자동 접수 | `CONTACT_STOPPED` + 자동 분쟁 | ✅ |
| 복귀 자리에 다른 차 | P 체결 후 알림, 통로를 막으면 같은 토큰으로 1m 정리 이동 1회, 비켜준 자리는 '잠시 비운 자리'로 빈자리 안내 제외 | `TIDY` → `RETURN_BLOCKED`, `tempVacated` | ✅ |
| 12V 저전압 / 고전압 최저치 | 요청 자체를 받지 않음 | `LOW_BATTERY` (12V 값은 SDK에 없어 데모 값) | ✅ |

## 3. 기능 2 · 빈자리 레이더

| 요구사항 | 구현 | 상태 |
|---|---|---|
| 1단계 출차 신호: 주차 → 주행 전환 시 그 자리를 '방금 빈 자리'로 공유 | Gear P/N → D/R 전환 (비켜줘 이동 중 제외) | 구현 |
| 위치: 게이트 통과부터 추측항법, BLE 비콘 보정, 처음 몇 번은 차주가 '내 자리' 선택 | 지오펜스 진입 = 게이트, 주차 후 '내 자리' 선택 화면 | 부분 (BLE 비콘 보정은 2단계) |
| 받는 사람: 게이트를 지나 아직 주차하지 않은 차만 | arrivals (waiting) | 구현 |
| 순번: 게이트 통과 시각 순, 한 자리는 한 대에게만, 60초 무응답이면 다음 | `match()`, 60초 타이머 | 구현 |
| 범위: 같은 층·구역 우선, 가까운 순 | 점수화 (층 > 구역 > 거리) | 구현 |
| 선호: 우리 동 입구 근처, 넓은 칸. 충전기 칸은 충전이 필요한 전기차만, 장애인 칸 제외 | `eligible()` / `score()` | 구현 |
| 변경: 먼저 차면 "자리가 찼어요" + 다음 자리 | `onSpotTaken` | 구현 |
| 제외: 비켜줘 실행 중 '잠시 비운 자리' | `tempVacated` | 구현 |
| 빈도: 운전 중 음성 1회 + 화면, 한 번 입차에 최대 2건 | TTS 1회, `maxOffersPerArrival` | 구현 |
| 보상: 출차 신호·센서 스캔 참여 차에 소액 크레딧 | 출차 신호 +10, 옆 칸 확인 +5 | 구현 |
| 옆 칸 확인: 빈 칸 양옆에 주차된 참여 차가 확인 신호를 보탬, 안내 문구에 "옆 차 N대가 확인했어요" | `witnessesOf()` (지금은 주차 위치로 판정, 반경 6m) | 부분 (센서 판정은 2단계) |
| 2단계 센서 스캔 (초음파 10초) | SDK에 초음파 API 없음 | 2단계 |

## 4. 기능 3 · 트렁크 드롭

| 요구사항 | 구현 | 상태 |
|---|---|---|
| 차주가 상대 계정을 지정해 1회 개방 토큰 (10분, 지하주차장 안) | `POST /api/trunk-tokens` | 구현 |
| 넣어 주세요(당근 거래·택배) / 꺼내 가세요(빌려준 물건·판 물건) 두 용도 | `purpose: drop / pickup`, 닫히면 "물건이 도착했어요" / "물건을 가져갔어요" | 구현 |
| 주는 쪽이 차 옆에서 '열기' → 테일게이트만 열림, 실내 도어는 잠김 | 차량 앱 `Door.setDoorPosition(REAR)` | 구현 |

## 6. 기획서에 반영하면 좋은 점 (구현하면서 발견)

1. **DrivingMode → Gear**: 주차·출차 판정은 Gear API로 합니다. DrivingMode는 에코/스포츠 모드라 맞지 않습니다.
2. **비상등 → 미등 점멸**: 비상등 API가 없습니다. 촬영·이동 고지는 미등 점멸로 구현했습니다.
3. **Seat(착석 센서) 추가**: "차 안에 사람·반려동물 감지"를 실제로 하는 API입니다. SDK 매핑 표에 넣으면 "Vehicle SDK 안에서 6개 API"가 됩니다 (Gear, Door, Seat, EvBattery, Odometer, Light).
4. **충전 케이블 → 충전 중**: SDK는 충전 상태를 줍니다.
5. **경사 판정**: 차량 기울기 API가 없어 단지 지도의 경사 구역으로 판정합니다.
6. **12V 저전압**: 3rd party가 읽을 수 있는 값이 없습니다 (경고등은 signature 권한).
